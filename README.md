# Youth Life Agent

청년의 주거, 생활지원, 전세계약 위험 관련 질문에 대해 사용자의 상황을 확인하고 관련 문서를 기반으로 답변하는 LangGraph 기반 AI 에이전트 프로젝트입니다.

## 프로젝트 목적

기존 RAG 방식이 문서 검색 후 답변 생성에 초점을 둔다면, 이 프로젝트는 LangGraph를 활용해 사용자의 질문 유형을 분류하고 필요한 정보를 확인한 뒤 적절한 문서 검색 흐름으로 분기하는 것을 목표로 합니다.

## 주요 기능 예정

- 사용자 질문 유형 분류
- 청년월세지원, 청년수당, 전세사기 예방 문서 라우팅
- 부족한 사용자 정보 확인
- PDF 기반 RAG 검색
- 문서 근거 기반 답변 생성

## 사용 자료

- 2026년 서울시 청년월세지원 모집 공고
- 2026년 서울시 청년월세지원 FAQ
- 전세사기 예방 A to Z
- 청년수당 참여자 안내책자

## 기술 스택

- Python
- LangGraph
- LangChain
- ChromaDB
- OpenAI API
- PDF RAG
